# Unit Tour — 외부 공유용 빌드

원본 `Unit_Tour_standalone.html`(25.9MB)을 외부 공유 가능한 크기로 재패키징한 결과물.

## 공유 링크

Artifact: https://claude.ai/code/artifact/ca4a818e-6ea5-46df-8caf-4effd6411714
(기본은 비공개. 페이지 우측 상단 공유 메뉴에서 링크 공개로 전환해야 외부에서 열림)

## 파일

- `Unit_Tour_standalone.html` — 단독 실행본. 파일을 브라우저로 열면 그대로 동작 (6.0MB)
- `artifact-body.html` — Artifact 게시용. 외곽 `<html>/<head>/<body>` 태그를 제거한 본문 조각

두 파일의 내용물은 동일하며, 번들 부트스트랩이 실행 시 document 전체를 교체하는 구조라
조각 형태로 감싸져도 동일하게 렌더링된다.

## 원본 대비 변경점

에셋 3종만 재인코딩했고 UI·로직·폰트는 원본 그대로다.

| 에셋 | 원본 | 변경 후 |
|---|---|---|
| 평면도 (5000×4500 PNG) | 15.0MB | WebP 3000×2700 q90 — 466KB |
| 입체 평면 (1857×1011 JPEG) | 350KB | WebP q86 — 41KB |
| 미니맵 (698×405 PNG) | 126KB | WebP q88 — 35KB |

전체 25.9MB → 6.0MB. 알파 채널은 유지했고, 화면 최대 표시 크기(1085×1904 스테이지의
150/170px 패딩 안쪽)를 기준으로 여유 있게 잡은 해상도라 육안 손실은 없다.

## 알려진 제약

파노라마 이미지가 번들에 들어있지 않다. `<x-dc>` 스크립트가 각 공간의 텍스처를
`pano/0.jpg` ~ `pano/14.jpg` 상대 경로로 참조하는데 매니페스트에는 해당 파일이 없어,
360 뷰 영역은 WebGL 폴백 단색(#e6e6e4)으로 표시된다. UI·평면·아이소·미니맵·타입 전환은
정상 동작한다. 실제 파노라마를 붙이려면 15장의 equirectangular 이미지를 번들 매니페스트에
추가하고 `rooms` getter의 `src` 경로를 해당 uuid로 바꿔야 한다.
